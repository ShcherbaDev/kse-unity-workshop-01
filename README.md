# Flappy Bird-lite

Лабораторна робота №1 з Unity, варіант 6 (Flappy Bird-lite).

## Керування

- Стрибок: Space / ЛКМ / тап по екрану

## Що реалізовано

- Гравець із контролем через New Input System (клавіатура / миша / дотик)
- Нескінченна генерація пар труб з випадковою висотою gap і despawn за межами камери
- Поступове прискорення труб (з обмеженням максимальної швидкості, щоб це було реально проходити)
- Game Over при зіткненні з трубою або вильоті за межі екрана
- Рахунок на екрані під час гри та на екрані Game Over
- Екрани Main Menu та Game Over

## Що не встигли реалізувати

- Збереження найкращого результату
- Пауза під час гри
- Налаштування гучності / кнопка mute
- Візуальні ефекти при наборі очка та при смерті (партікли, тряска камери)
- Фон паралакс не покриває весь екран на дуже широких співвідношеннях сторін

## Що додано поза завданням лабораторної

- Фон паралакс
- Анімація екранів меню на DOTween (виїзд знизу, і типу здування вітром убік)
- Звукові ефекти (див. `Assets/Audio/CREDITS.txt`)
- Анімація персонажа
